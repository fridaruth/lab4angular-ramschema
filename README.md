# Lab 4, Angular - Ramschema

Detta är en reaktiv Angular-applikation, byggd för laboration 4 i kursen Programmering i TypeScript. Den hämtar ett ramschema över kurser, presenterar datan och tillåter sökning och sortering i realtid.

## Funktioner

* **Signals & Computed:** Hämtar data, filtrerar sökningar och sorterar kolumner.
* **Live-sökning:** Sök direkt på kurskod eller kursnamn. 
* **Sortering:** Klicka på rubriker för att sortera.
